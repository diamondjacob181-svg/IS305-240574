This project demonstrates the use of JavaScript OOP concepts including classes, objects, constructors, private fields, getters, setters, and methods.
It simulates a Dining Meal Booking system where students can book meals, specify dietary notes, and view a formatted receipt with calculated costs.
Submitted Files

DiningApp.js → Main application file that creates a booking object and prints a formatted receipt to the console.

MealBooking.js → Class definition file containing private fields, constructors, getters/setters, and methods for calculating meal costs and generating booking summaries.

How to Run the Program

Ensure both files (DiningApp.js and MealBooking.js) are saved in the same folder.

Open a terminal in that folder.

Run the program with the following command:

bash

node DiningApp.js
